# Placental Drug Transfer Model

Code and data associated with the study:

**Integrated machine learning framework for quantitative prediction and classification of human placental drug transfer**

## Repository contents

```text
placental-transfer-model/
├── data/
│   ├──  Supplementary Dataset S1.xlsx
│   └──  selected_xml.zip
├── code/
│   ├── 01_build_final_models.py
│   └── 02_llm_fda_labeling.py
├── .gitignore
└── README.md
```

## Files

- `data/Supplementary Dataset S1.xlsx`  
  Final training datasets for the CI and F/M prediction models.

- `code/01_build_final_models.py`  
  Reconstructs the final CI and F/M machine learning models.

- `code/02_llm_fda_labeling.py`  
  Reproduces the LLM-based classification of FDA drug labels used for external evaluation.

- `selected_xml.zip`  
  Curated FDA Structured Product Labeling (SPL) XML files used as input for the LLM analysis.
